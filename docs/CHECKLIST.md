# Agent 一页实施清单

| 阶段 | 做什么 / 目的 | 放行条件 | 失败后去向 |
|---|---|---|---|
| G0 | 核对模型许可、源码、分片SHA和旧服务 | 确定非量化Mage-VL；明确资源归属 | 制品/源码差异审查，不重新猜架构 |
| G1 | 保留平台Torch/NPU/CANN，小算子探针 | 真NPU计算、设备映射和剩余HBM | 驱动/镜像配套排查，不盲装CUDA |
| G2 | 两图×冷暖生成 | 诊断空、视觉一次、整数布局、EOS、语义相关 | loader/cache/prompt分层定位 |
| G3 | 原生视频16帧 | 真实时间戳/patch/token/预算与EOS | processor预算与解码核对 |
| G4 | gate独立oracle与前缀 | FP32 gate完整对照与离散决策通过 | 保留BF16失败，不调门槛 |
| G5 | 同条件stream_fast | 全输入到输出等价、计时口径一致 | 先拆媒体与计算时间 |
| G6 | 可选驻留服务/本机调用 | 认证、request ID、真实上传结果、unknown审计 | 不重放，不按端口杀进程 |
| G7 | 录像RTSP测试源 | CPU像素/PTS→模型gate→实际响应分别通过 | 关键帧/超时/PTS/队列分层定位 |
| G8 | 回归/打包/记录 | 旧业务可用、证据与范围明确、发布扫描通过 | 回退自己改动，保留原件 |

在任何阶段停止无依据的升级、全局monkeypatch和重复失败尝试；同错误两轮无新信息则缩小复现或变更定位层级。健康成功不替代推理，EOS不替代准确率，HTTP超时不等于未执行。
